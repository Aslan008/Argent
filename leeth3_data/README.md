# Leeth 3: данные от учителя (папка для Antigravity)

Эта папка — рабочее место агента-генератора (Gemini в Antigravity). Откройте в Antigravity **только эту папку**
(`Argent/leeth3_data`), не весь проект: агент не должен видеть остальной код и экзамены.

## Как запустить (для владельца)

Откройте папку в Antigravity и скажите агенту:

> Прочитай `AGENT.md` и обработай очередь `queue/` до конца (или: обработай 5 пакетов).

Агент берёт пакеты по одному, пишет результат в `incoming/`, переносит выполненный пакет в `queue/done/`.
После этого в Argent (или попросите Claude):

```
.venv\Scripts\python.exe scripts\leeth3_ingest.py
```

Скрипт проверит каждую строку и напишет, сколько принято и почему отклонено (отчёты — в `reports/`).
Новые пакеты создаёт `scripts\leeth3_queue.py`.

## Что где

| Папка/файл | Что |
|---|---|
| `AGENT.md` | инструкция агенту: процесс и правила качества |
| `FORMAT.md` | формат строки JSONL с примерами для каждого типа вопроса |
| `requests/` | спецификации заданий (что генерировать и как) |
| `queue/` | пакеты к выполнению; `queue/done/` — выполненные |
| `incoming/` | результаты агента (JSONL) |
| `accepted/`, `rejected/`, `reports/` | заполняет скрипт приёма |
