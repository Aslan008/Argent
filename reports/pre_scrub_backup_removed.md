# Удалён локальный backup-ref старой истории

Дата: 2026-10-23

Удалён локальный ref `refs/backup/pre-scrub-master` (SHA `ef2b3f98815e92b5afc05a19594ca7c2b2c79af8`).

Причина: он удерживал pre-scrub историю с блобами `src/leeth/data_400m/leeth.onnx`
(1.29 ГБ × несколько версий) и `src/leeth/data_400m_smoke/leeth_400m_last.pt` (1.9 ГБ),
из-за чего `.git` занимал ~29.7 ГБ, а свободное место на диске заканчивалось.

Если старая история когда-нибудь понадобится — её можно восстановить только из
внешней копии; локально объекты удалены `git gc --prune=now`.
