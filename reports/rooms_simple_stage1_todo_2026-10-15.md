# Комнаты: простота уровня Scratch, этап 1 (2026-10-15)

Ограничения: ничего не пушить и не коммитить без просьбы; текущие возможности не терять; корневые фиксы;
тесты — только `.venv\Scripts\python.exe` через обёртку; живая проверка редактора в браузере.

## Цель
Обычный человек собирает комнату без знания `{{task}}`, `state.x`, `writes`, JSON-формата и `sets`;
при этом остаются все прежние возможности (расширенный режим) и появляются новые полезные.

## A. Движок
- [x] A1. Блок `git` (status, diff, log, add, commit, branch, checkout, stash, pull, push): результат в поля, без разбора текста
- [x] A2. `save_as` у любого блока с результатом («Запомнить как»): простая замена `sets`/`writes` для 90% случаев
- [x] A3. Агент без `writes`: ответ текстом сам становится `<id>.output` и `save_as`
- [x] A4. Валидатор/диаграмма/доска/библиотека/сервер редактора/подтверждения: git везде учтён
- [x] A5. Инструмент `rooms` для LLM: git-блок и save_as доступны в create/patch, описание в схеме и builder

## B. Редактор
- [x] B1. Палитра по задачам (Файлы, Git, Команды, Думать, Решать, Сеть, Сообщить), цветные блоки, говорящие имена
- [x] B2. Простой/расширенный режим формы блока (по умолчанию простой: 1–3 поля), запоминается
- [x] B3. Переменные-«пилюли»: что известно на этом шаге, клик вставляет, понятные имена
- [x] B4. Агент: «Что сделать» + «Запомнить ответ как»; «Что вернуть», инструменты, лимиты — в расширенный
- [x] B5. Git-блок: форма без команд, режимы словами
- [x] B6. Человеческие подписи ошибок валидатора

## C. Проверка
