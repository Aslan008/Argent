# Obsidian Notes

Use `write_file` for creating notes with ABSOLUTE paths (e.g., `vault/Note.md`).
Format new notes with YAML frontmatter at the top (e.g.,
```yaml
---
tags: [idea, research]
aliases: []
---
```
).
Use `read_file` and `multi_replace_in_file_chunk` for reading and editing existing notes.
Use `grep_search` to search through notes in the vault.
