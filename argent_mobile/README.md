# 📱 Argent Mobile

Полноценное, независимое мобильное приложение-ассистент для смартфонов (Android), объединяющее мощь облачных моделей и автономность оффлайн-моделей прямо на чипе устройства.

---

## ✨ Возможности

1. **Два режима работы сразу (переключатель в шапке):**
   - 🌐 **Онлайн (быстрый)**: подключение к DeepSeek, OpenAI, OpenRouter, Groq или домашней Ollama по Wi-Fi.
   - 📴 **Оффлайн (на чипе телефона)**: автономная работа без интернета (движок WebLLM на WebGPU). Модели Qwen 2.5, Llama 3.2 скачиваются один раз в память устройства.
2. **Рассуждения и аудит решений:**
   - 🧠 **Ход мыслей (`<think>`)**: раскрывающаяся карточка с размышлениями модели.
   - 🔍 **Перепроверка (`<rethink>`)**: выделенный блок самопроверки ответа на ошибки.
3. **Файловый менеджер проекта:**
   - Сохранение сгенерированного кода в файлы проекта в один клик.
   - Просмотр, редактирование и скачивание файлов прямо на накопитель телефона.
4. **Установка на Android в один клик (PWA / APK):**
   - Мгновенная установка прямо из браузера смартфона на домашний экран.
   - Готовая конфигурация Capacitor (`capacitor.config.ts`) для компиляции в `.apk`.

---

## 🚀 Как запустить прямо сейчас:

1. Дважды кликните по файлу **`start_mobile.bat`** внутри папки `ArgentMobile` на Рабочем столе.
2. На телефоне, подключенном к вашему Wi-Fi, откройте в браузере:
   ```
   http://192.168.0.100:3000
   ```
3. В меню браузера Chrome на Android выберите **«Добавить на главный экран»** (или «Установить приложение»).
4. На вашем телефоне появится отдельная иконка приложения **Argent**, открывающаяся на весь экран без рамок браузера!
