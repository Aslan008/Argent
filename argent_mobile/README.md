# Argent Mobile

Мобильный ассистент для Android: облачные модели (DeepSeek, OpenRouter, Groq, OpenAI, домашняя Ollama
по Wi-Fi) и модели прямо на телефоне — файлы GGUF через нативный llama.cpp (в APK) или модели WebLLM на
WebGPU.

## Возможности

1. **Онлайн и оффлайн** — переключатель в шапке.
   - Онлайн: любой OpenAI-совместимый сервер. Ошибка посреди ответа (например, у апстрима OpenRouter)
     показывается текстом, а не пустым ответом.
   - Оффлайн: `.gguf` с телефона (llama.cpp, только в APK; шаблон чата берётся из самой модели) или модель
     WebLLM из списка (WebGPU).
2. **Окно контекста.** История подрезается со старого конца под окно модели (облако — 32k токенов,
   WebLLM — 4096, GGUF — 2048/4096/8192 на выбор в настройках). Когда старые сообщения не поместились, над
   ответом появляется заметка.
3. **Ход мыслей и перепроверка** — `<think>` / `<rethink>`, а также рассуждения из `reasoning_content`
   (DeepSeek) и `reasoning` (OpenRouter, Ollama).
4. **Файлы проекта** — сохранение кода из ответа, редактирование; «Скачать» в APK пишет в
   «Загрузки/Argent», в браузере — обычное скачивание.
5. **Автопилот телефона** (только APK, служба специальных возможностей): «открой приложение Telegram»,
   «домой», «назад».

## Запуск в браузере (PWA)

1. `start_mobile.bat` (или `npm run dev`).
2. На телефоне в той же сети Wi-Fi откройте адрес, который напечатает скрипт (`http://<IP-ПК>:3000`).
3. В Chrome: «Добавить на главный экран».

WebGPU-модели в Chrome на Android требуют HTTPS или APK. Для домашней Ollama на ПК задайте
`OLLAMA_HOST=0.0.0.0` и `OLLAMA_ORIGINS=*` и откройте порт 11434 в брандмауэре.

## Сборка APK

Нужны Android SDK + **NDK** и исходники **llama.cpp** в `android/app/src/main/cpp/llama.cpp` (в
репозиторий они не входят):

```
npm install
npm run build
npx cap sync android
cd android && gradlew assembleDebug
```

`npx cap sync` переносит `capacitor.config.ts` (в том числе `allowMixedContent` для запросов к
`http://192.168.x.x` из приложения) в Android-проект.

## Проверки

```
npm run check     # типы TypeScript + тесты (разбор SSE, окно контекста, настройки, парсер тегов)
```
